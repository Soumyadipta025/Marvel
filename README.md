# Marvel Multiverse Landing Page

A cinematic Marvel-inspired landing page built using pure HTML, CSS and JavaScript.

This project was created to showcase modern frontend design skills using only core web technologies without any frameworks or external UI libraries.

The UI focuses on smooth animations, glowing visual effects, interactive sections and a premium cinematic experience inspired by the Marvel universe.

---

# Live Features

- Animated wave background
- Floating particle effects
- Smooth scroll reveal animations
- Mouse glow interaction
- Cinematic Spider-Man hero section
- Glassmorphism character cards
- Marvel timeline section
- Featured movies section
- 3D flip movie card animation
- Character detail popup modal
- Responsive design
- Counter animations
- Premium black and red theme

---

# Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

No Bootstrap, frameworks or external libraries were used.
